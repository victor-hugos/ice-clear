# Ice Clear Web

Frontend do MVP `Ice Clear`.

## Stack

- `React`
- `Vite`
- `Tailwind CSS`
- `React Router`
- `Supabase JS` preparado para integracao futura

## Scripts

```bash
npm run dev
npm test
npm run lint
npm run build
```

## Observacao

Nesta fase, parte relevante do fluxo ainda opera com armazenamento local para acelerar a validacao do produto antes da conexao real com `Supabase`.
